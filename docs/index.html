01Что внутри

Карусель по кругу

Все установленные приложения в кольце: 7 плиток на экране, конец списка плавно переходит в начало.

Два экрана

«Кино» из видео и «Классика» — прежний вид CleanYourTV 3.2. Переключение с пульта, выбор запоминается.

Погода в шапке

Стеклянная плашка: иконка, температура, короткое описание. Город по публичному IP, кэш 30 минут.

Кнопка VPN

Круглая кнопка: зелёная — VPN включён, красная — выключен. Открывает настроенное приложение VPN.

Звуки карусели

Мягкий «тик» при смене фокуса и глубокий «тук» подтверждения. Синтезируются кодом, без файлов.

Третий экран

«Универсальный» в духе Google TV: фотообои, «Избранное» и «Все приложения», кнопка VPN.

DeepSeek-помощник

Микрофон в верхнем баре: голосовые команды, ответы DeepSeek и озвучка. Ключ хранится только на ТВ.

Плавность

5.46 % «дёрганых» кадров, медиана 11 мс, p90 28 мс, 0 пропущенных vsync. Карусель не пересчитывает разметку.

02Три домашних экрана

«Кино» — часы и дата в углу, погода, круглые кнопки, морозный док на фотообоях, бесконечная карусель.
«Классика» — прежний домашний экран CleanYourTV 3.2: приветствие, док-карточки, строки приложений.
«Универсальный» — Google-TV-стиль: фотообои, «Избранное» и «Все приложения», DeepSeek-помощник.

03Универсальный экран

Экран в духе Google TV на Jetpack Compose: фотообои, минималистичный верхний бар и два ряда карточек. Работает на любом Android TV 8.0+ и приставке, масштабируется под HD, Full HD и 4K.

Кнопка-домик в баре открывает выбор домашнего экрана.

Верхний бар: микрофон DeepSeek, домой, VPN (зелёная/красная), сеть, уведомления, поиск, настройки лаунчера, настройки TV, погода и часы.

Ряды: «Избранное» и «Все приложения»; OK открывает приложение, долгое OK — меню (в избранное, порядок, сведения). В настройках: обои (озеро / закат / ночь / автосмена), звуки, громкость, заставка.

04DeepSeek-помощник

Микрофон в верхнем баре открывает помощника. Речь распознаётся на телевизоре, ответ показывается и озвучивается. Локальные команды работают без сети: «Открой YouTube», «Включи VPN», «Погода», «Громче», «Кино», «Классика». Всё остальное уходит в DeepSeek (deepseek-chat).

Вопрос голосом или текстом — ответ DeepSeek и озвучка TTS.
Ключ DeepSeek хранится только на телевизоре: палитра → «DeepSeek: ключ» или файл deepseek_key.txt через adb. В APK и репозиторий он не попадает.

05Карусель в движении

Приложения идут по кругу: конец списка плавно переходит в начало, выбранная плитка увеличивается и получает белое кольцо. Запись с телевизора (YouTube → Кинопоиск → VK Видео → RuTube):

Записано на Philips 50PUS8057/60; вживую анимация плавнее — 12 fps здесь ограничены GIF.

06Плашка с названием

Над выбранной плиткой — нейтральное название в стиле экрана. Два варианта, переключение там же в меню:

«Стекло» — тёмная стеклянная плашка (по умолчанию)
«Без фона» — только название с мягкой тенью

07Переключение экранов

Удерживайте ОК на кнопке «Настройки» в шапке — откроется меню:

  • «Плашка: …» — стиль названия (только на экране «Кино»);
  • «Экран: Кино / Классика» — смена домашнего экрана;
  • там же — настройки главного экрана и карточки приложений.

Выбор запоминается и переживает перезагрузку телевизора.

Меню открывается удержанием ОК на «Настройки».

08Погода и приватность

Погода берётся без API-ключей: город определяется по публичному IP (ipwho.is), прогноз — из wttr.in, резерв — api.met.no. Значение кэшируется на 30 минут и показывается сразу при возврате на Home.

В лаунчер добавлено разрешение INTERNET — только для этого запроса. Больше сетевых обращений нет: ни телеметрии, ни аналитики, ни фоновых сервисов. Без сети остаётся последнее значение.

10Установка

Скачайте APK и поставьте по ADB (или с флешки любым файловым менеджером):

adb connect 192.168.0.39:5555
adb install -r CleanYourTV-ThreeScreens-4.0.2.apk
APK подписан тем же debug-ключом, что прежние сборки CleanYourTV 3.2/3.4 — ставится обновлением поверх: роль «Домой», настройки и данные сохраняются. Нужен Android TV 8.0+ (minSdk 26, targetSdk 34).

11Сборка из исходников

git clone https://github.com/mosloboev444-hue/tv-cinema-launcher
cd tv-cinema-launcher/launcher
echo "sdk.dir=/путь/к/Android/Sdk" > local.properties
./gradlew assembleRelease

Нужны JDK 17+ и Android SDK 34. Патчи к чистому upstream 3.4 — в папке patch/.
